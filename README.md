# Task Tracker API

A REST API built with TypeScript, Express, and SQLite.

## Features

- Create new tasks
- Retrieve all tasks or a specific task
- Update task titles and completion status
- Delete tasks
- Store tasks persistently using SQLite
- Validate incoming requests
- Automated API tests using Vitest and Supertest

## Technologies

- **Node.js** — JavaScript runtime
- **TypeScript** — Type-safe JavaScript
- **Express** — Web framework
- **SQLite** — Database
- **better-sqlite3** — SQLite database driver
- **Vitest** — Testing framework
- **Supertest** — HTTP endpoint testing
