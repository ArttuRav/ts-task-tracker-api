# Task Tracker API

A REST API built with TypeScript, Express, and SQLite.

## Features

- Create new tasks
- Retrieve all tasks or a specific task
- Update task titles and completion status
- Delete tasks
- Store tasks persistently using SQLite
- Validate incoming requests
- Automated API tests using Vitest and Supertest

## Technologies

- **Node.js** — JavaScript runtime
- **TypeScript** — Type-safe JavaScript
- **Express** — Web framework
- **SQLite** — Database
- **better-sqlite3** — SQLite database driver
- **Vitest** — Testing framework
- **Supertest** — HTTP endpoint testing

## API Endpoints

The API provides the following endpoints for managing tasks:

| Method | Endpoint | Description |
|---|---|---|
| GET | `/tasks` | Retrieve all tasks |
| GET | `/tasks/:id` | Retrieve a specific task |
| POST | `/tasks` | Create a new task |
| PATCH | `/tasks/:id` | Update an existing task |
| DELETE | `/tasks/:id` | Delete a task |

### Task Structure

Each task contains three properties:

```json
{
  "id": 1,
  "title": "Learn TypeScript",
  "completed": false
}
```

- `id` — Unique task identifier generated by SQLite.
- `title` — Description of the task.
- `completed` — Boolean indicating whether the task is completed.

## Getting Started

### Prerequisites

- Node.js (version 24 or later recommended)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ArttuRav/ts-task-tracker-api.git
   ```

2. Navigate into the project directory:

   ```bash
   cd ts-task-tracker-api
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a local environment configuration by copying `.env.example` to `.env`.

   On Windows PowerShell:

   ```powershell
   Copy-Item .env.example .env
   ```

### Running the API

Start the development server:

```bash
npm run dev
```

By default, the API runs at:

`http://localhost:3000`

You can change the port and SQLite database filename in `.env`.

### Running Tests

Run the automated tests:

```bash
npm test -- --run
```

Run the tests and TypeScript type checking together:

```bash
npm run check
```

### Building for Production

Compile TypeScript into JavaScript:

```bash
npm run build
```

Start the compiled application:

```bash
npm start
```

## API Usage Examples

The following examples use PowerShell and assume the API is running at `http://localhost:3000`.

### Get All Tasks

```powershell
Invoke-RestMethod -Uri "http://localhost:3000/tasks" -Method Get
```

### Get a Specific Task

```powershell
Invoke-RestMethod -Uri "http://localhost:3000/tasks/1" -Method Get
```

### Create a Task

```powershell
Invoke-RestMethod -Uri "http://localhost:3000/tasks" -Method Post -ContentType "application/json" -Body '{"title":"Learn TypeScript"}'
```

### Update a Task

Mark task 1 as completed:

```powershell
Invoke-RestMethod -Uri "http://localhost:3000/tasks/1" -Method Patch -ContentType "application/json" -Body '{"completed":true}'
```

### Delete a Task

```powershell
Invoke-RestMethod -Uri "http://localhost:3000/tasks/1" -Method Delete
```

**Note:** Replace task ID `1` with an existing task ID when testing. If you've configured a different port in `.env`, update the URLs accordingly.
